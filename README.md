## 📌 Project Overview

This project focuses on analyzing sales performance and business trends using SQL, Microsoft Power BI, and Tableau.

The analysis involves querying and exploring business data, identifying key performance indicators, and developing interactive dashboards to support data-driven decision-making.

The project demonstrates practical skills in data analysis, SQL querying, business intelligence, and data visualization.

---

## 🎯 Objectives

- Analyze sales performance and business trends.
- Perform SQL-based data analysis and extract meaningful insights.
- Identify key performance indicators (KPIs).
- Explore product, customer, and regional performance.
- Develop interactive dashboards using Power BI and Tableau.
- Present analytical findings through clear and effective visualizations.
